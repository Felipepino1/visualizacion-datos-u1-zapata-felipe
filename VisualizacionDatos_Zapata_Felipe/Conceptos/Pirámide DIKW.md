# Pirámide DIKW

## Definición
Modelo jerárquico Datos → Información → Conocimiento → Sabiduría (*Data, Information, Knowledge, Wisdom*). Cada nivel agrega contexto, significado y capacidad de acción al anterior.

## Resumen Personal
Este modelo me ayudó a ordenar las notas de la bóveda: abajo los datos crudos, arriba las decisiones. La visualización funciona como el «ascensor» que acelera el paso entre niveles.

## Importancia
Permite ubicar en qué etapa está un proyecto: si solo tengo tablas, estoy en datos; si tengo un dashboard que alguien usa para decidir, estoy en conocimiento.
